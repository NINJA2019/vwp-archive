## 1. 概要

### 何が変わるか
- モバイル版（700px以下）のUI導線を全面刷新
- 既存の3ビュー（グリッド/リスト/タイムライン）に代わり、**カードスワイプUI**を採用
- メンバー選択はWELCOME画面に集約し、メイン画面のフィルターバーは**タグ絞り込み**に置き換え

### 設計思想
- **「LPレコードを漁る体験」のモバイル翻訳**: PC版のターンテーブル＋棚のメタファーを、モバイルに最適化された縦スワイプのカードブラウジングに変換
- **情報の段階的開示**: メンバー選択（WELCOME）→ 曲カードブラウズ → タップでLP盤＋YouTube遷移、と3段階でシンプルに
- **雑多な情報を排除**: メンバーチップ・ビュー切替・複雑なフィルターバーを省き、S字ホイールとタグチップだけで導線を構築

### UIリファレンス
- **WELCOME画面**: AmazingUI「Music App UI/UX Interaction」— S字カーブ上の回転ホイールでメンバー選択
- **カードビュー**: Milkinside「Cards for music player」— 縦スワイプのカードスタックで曲ブラウズ

## 3. WELCOME画面仕様

### レイアウト: S字ホイール
- メンバーアイコン（丸形）が**縦のS字カーブ**に沿って配置
- **中央のアクティブアイコン**: 110px、メンバーカラーのリング＋グロー、左横にメンバー名表示
- **上下のアイコン**: 56px → 38px と徐々に縮小、透明度も低下
- **S字カーブ**: `Math.sin(dist * 0.8) * 70px` で左右にオフセット
- 画面に**3〜5個**のみ表示、それ以外は非表示

### メンバー順序と表示名
| 順番 | ID | 表示名（ラベル） | アイコン |
|---|---|---|---|
| 1 | vwp | V.W.P | V_W_P.png（全員集合画像） |
| 2 | kafu | KAF | KAF.png |
| 3 | rime | RIM | RIM.png |
| 4 | harusar | HARU | Harusaruhi.png |
| 5 | isekai | JOUCHO | isekaijocho.png |
| 6 | koko | KOKO | koko.png |
| 7 | all | ALL | グラデーション＋◆（アイコンなし） |

### 操作
| 操作 | 動作 |
|---|---|
| 上下スワイプ | ホイールが1個ずつ回転（慣性＋スナップ付き） |
| アイコンタップ | そのメンバーが中央にスナップ |
| PLAY ARCHIVE | トランジション演出 → カードビューに遷移（選択メンバーでフィルタリング） |
| TODAY'S OBSERVATION | 日替わり5曲モードでカードビューに遷移 |

### ビジュアル
- **背景**: `#050710`（ダーク）
- **アンビエントグロー**: 選択中メンバーのカラーが背景にぼんやり滲む（filter:blur(110px)）
- **S字パスライン**: SVGで薄いカーブライン描画（opacity 0.04〜0.06）
- **ヘッダー**: Cinzel「V.W.P ARCHIVE」＋ Barlow Condensed「UNOFFICIAL」
- **フェードインアニメーション**: ヘッダー → アイコン → ボタンの順にスタガー表示

## 4. カードビュー仕様

### カード構造（1枚）
```
┌─ Card ─────────────────────────────┐
│ [📌 ピンボタン]          (右上)     │
│                                     │
│  ┌─ サムネイル ──────────────────┐  │
│  │  YouTubeサムネ（object-fit:cover）│
│  │  グラデーションオーバーレイ     │  │
│  └───────────────────────────────┘  │
│                                     │
│  ── メンバーカラーバー（2px） ──    │
│  MEMBER NAME（メンバーカラー）      │
│  曲タイトル（Shippori Mincho）      │
│  2024-01-20                         │
│  [シングル] [系譜曲]                │
│                                     │
│         [▶ YOUTUBE]（タップ時表示）  │
│                                     │
└─────────────────────────────────────┘
```

### カードスタック表示
| 位置 | transform | opacity |
|---|---|---|
| 前面（data-pos="0"） | translateY(0) scale(1) | 1 |
| 背面1（data-pos="1"） | translateY(12px) scale(.97) | 0.55 |
| 背面2（data-pos="2"） | translateY(24px) scale(.94) | 0.3 |
| 非表示 | translateY(40px) scale(.9) | 0 |

### 操作
| 操作 | 動作 |
|---|---|
| 下スワイプ | 次の曲へ（カードが下に飛び出す） |
| 上スワイプ | 前の曲へ（カードが上に飛び出す） |
| カードタップ | LP盤が右側からスライドアウト＋YouTube CTAボタン表示 |
| ← 左スワイプ | **WELCOME画面に戻る**（メンバー選び直し） |
| 📌ボタン | MY SHELFに追加/削除 |
| YouTube CTA | 外部遷移（`window.open`） |

### ヘッダー（カードビュー）
| 要素 | 内容 |
|---|---|
| ロゴ | Cinzel「V.W.P ARCHIVE」＋「UNOFFICIAL」 |
| 検索バー | テキスト入力で曲名・メンバー名検索 |
| **タグチップ**（旧メンバーチップの位置） | 横スクロール、タップでフィルタリング |
| ソートバー | 「新しい順」＋件数表示 |

### タグチップ（メンバーチップの代替）
- **表示するタグ**: シングル、アルバム、カバー、ライブ、ワンマン、系譜曲 等
- メンバー絞りはWELCOME画面が担当するため、ここには不要
- 選択メンバー × タグの組み合わせで曲が絞り込まれる

### LP盤表示（タップ時）
- デフォルトは**完全非表示**（opacity:0, translate(105%)）
- タップ時にスライドイン: `transform: translate(40%,-50%) rotate(25deg); opacity:1`
- canvas描画: メンバーカラー半透明（`globalAlpha:0.55`）+ 溝 + 光沢 + ラベル
- YouTube CTAボタンも同時にフェードイン

### アンビエントグロー
- 前面カードのメンバーカラーが背景に滲む
- カード切替時に0.8秒でトランジション

## 5. 左スワイプ戻りの実装方針

### 検出方法
- `touchstart` で開始X座標を記録
- `touchmove` でX方向の移動量を追跡
- 移動量が `80px` 以上かつ方向が左 → WELCOME画面に遷移
- 縦スワイプ（カード送り）との競合防止: X移動量 > Y移動量の場合のみ左スワイプと判定

### トランジション
- カードビュー全体が右にスライドアウト（`translateX(100%)`）
- WELCOME画面が左からスライドイン
- メンバーホイールは前回の選択位置を保持

## 6. データフロー

```
WELCOME画面
  ↓ selectedMember = 'kafu' (例)
  ↓
カードビュー
  ↓ Supabase videos テーブルから取得
  ↓ WHERE member LIKE '%kafu%'
  ↓ selectedTag があれば AND tags LIKE '%シングル%'
  ↓ ORDER BY date DESC
  ↓ 無限スクロール（PAGE_SIZE=30をカードスタックに変換）
  ↓
  各カード:
    - サムネ: https://img.youtube.com/vi/{video_id}/mqdefault.jpg
    - メンバーカラー: getMemberColor(member)
    - LP盤: drawVinylDisc(canvas, memberColor, size)
    - YouTube遷移: window.open(url)
```
